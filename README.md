# Telegram Self-Destruct Downloader

Program that automatically saves **view-once / self-destruct** media from Telegram to **Saved Messages**.

---

## Download

Open **Releases** and download:

- **Windows** → `TelegramSelfDestructDownloaderwin.exe`
- **Linux** → `TelegramSelfDestructDownloaderlinux`

No installation needed.

---

## First-time setup (required once)

Telegram requires API access for desktop apps.

### Get API ID and API Hash

1. Open https://my.telegram.org
2. Log in with your phone number
3. Click **"API development tools"**
4. Fill the form (any app name is fine)
5. Copy:
    - **API ID**
    - **API Hash**

You will need them only once.

---

## How to use

1. Run the program
2. Enter **API ID**
3. Enter **API Hash**
4. Enter your phone number
5. Enter the login code from Telegram
6. Enter your Telegram password if asked

Leave the program running.

---

## What it does

- Works from your own Telegram account
- Automatically saves view-once media
- Sends it to **Saved Messages**
- Nothing is saved to disk
